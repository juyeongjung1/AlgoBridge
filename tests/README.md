# 回帰テスト

プロジェクトのルートで実行します。テストはアプリの入力・採点・コード生成・実行結果を読み込みます。テスト専用のサーバーは不要です。

## 判定・入力・出力・Javaの検証

問題文の公式・ルール・出力文字列と掲載例は、Node.jsだけで確認できます。

```powershell
node tests/lesson-content-regression.cjs
```

Node.jsとJDK 17以上が必要です。`java`と`javac`にPATHを通してください。

```powershell
node tests/problem-regression.cjs
```

全30問、宣言順・別解・誤配置・入力範囲・トレースを検証し、生成したJavaの実行結果を独立した期待値と比較します。JavaのソースとclassはOSの一時ディレクトリへ出力します。失敗時は終了コード1になります。

序盤9問の順序、分岐20問の候補総数（増量前の1.5倍を切り上げ）、追加候補の重複と誤採点も検証します。

## ブラウザの検証

Microsoft Edgeと、Node.jsから読み込めるPlaywrightが必要です。

```powershell
node tests/browser-regression.cjs
```

Playwrightがプロジェクト外にある場合は、その`node_modules`ディレクトリを環境変数`AUDIT_MODULES`に指定できます。

全問の模範配置、表示、コード対応、分岐幅、保存、取り消し、入れ子ドラッグ、講師モード等を検証します。新規ブラウザ環境を使うため、普段の正解履歴には触れません。図の検証画像はOSの一時ディレクトリへ保存します。

問題文とナビゲーションの固定、クリック時のドラッグ案内、正解済みの問題リスト表示と次ボタンの強調、変数名の注記、手操作入力記号の一致も確認します。

外部ロゴの配信状況で機能テストが停止しないよう、検証用ブラウザではその画像への通信だけを抑止しています。ロゴそのものの表示はこのテストの対象外です。

これらの開発用ランタイムは、通常のアプリ利用には不要です。

## 原因ブロックの表示

```powershell
node tests/diagnostics-regression.cjs
node tests/diagnostics-browser.cjs
```

前者はNode.jsだけで、全30問・許容別解・深い分岐・二重ループ・順序・宣言不足・複数の原因を検証します。診断が配置を変更しないことも確認します。

後者は上記と同じPlaywright・Microsoft Edgeの環境で、赤枠が原因の階層の見出しだけを囲むこと、複数表示、確認箇所への移動、穏やかな点滅、動きを抑える設定、修正・取り消し・問題切替時の表示解除を検証します。画像は一時ディレクトリに保存します。
